Methodology

  • Both binaries were built and executed with Windows .NET SDK 10.0.300 in Release mode from the same F: volume.
  • Each cohort used one fresh process per seed with the same settings and runtime environment.
  • Comparison baseline: sm-search-baseline-v3@fcd37dea.
  • Current implementation: sm-inventory-cache-v4@ac5d235c. Detailed counters are opt-in and use local hot-loop accumulation.
  • Paired cards and phase totals use the 30 common successful seeds. Reliability and scatter plots use all 30 attempts.
