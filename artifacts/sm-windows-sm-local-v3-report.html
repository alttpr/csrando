Methodology

  • Both binaries were built and executed with Windows .NET SDK 10.0.300 in Release mode from the same F: volume.
  • Each cohort used one fresh process per seed with the same settings and runtime environment.
  • Comparison baseline: sm-search-baseline-v2@42e763ab.
  • Current implementation: sm-local-v3@e305a7a5. Detailed counters are opt-in and use local hot-loop accumulation.
  • Paired cards and phase totals use the 50 common successful seeds. Reliability and scatter plots use all 50 attempts.
