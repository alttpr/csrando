Methodology

  • Both binaries were built and executed with Windows .NET SDK 10.0.300 in Release mode from the same F: volume.
  • Revisions were alternated per seed, main first and final second, with one fresh process for each attempt.
  • Pinned main is c50d6f04 plus measurement-only timing/allocation/hash instrumentation. Its search and fill behavior is unchanged.
  • Final branch is a16a44c8. Detailed counters are opt-in and use local hot-loop accumulation.
  • Paired cards and phase totals use the 44 common successful seeds. Reliability and scatter plots use all 50 attempts.
