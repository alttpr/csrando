# Randomizer Information

## Welcome to the Quad? Randomizer Beta

### Quick helpful notes
	* This is a randomizer that combines Super Metroid, A Link to the Past, Metroid 1 and Zelda 1.
	* The portal to Zelda 1 is the Kakariko Fortune Teller
	* The portal to Metroid 1 is the Lumberjack hut
	* More portals will be added later
	* For the "Ganon" goal, all final bosses are required to be defeated to beat the game
	* For the "TriforceHunt" goal, find 66 out 100 pieces and turn it in near hyrule castle
	* The SM logic is similar, but not the same, as SMZ3 normal logic where IBJ can be required. No hellruns are required.
	* In Z1 and M1 you can use Up+B on the second controller when paused to "die" and restart at the start of a dungeon/area

### Some known issues
	* The portal from Metroid 1 is janky and you might need to go back and forth to make it work inside Metroid 1
	* Some palette issues and color issues with items
	* The starting menu doesn't do anything useful right now since the game always starts in SM
	* The placement logic isn't fully completed so some locations might not be properly randomized
	* Selecting "Retry" in Zelda 1 will brick your save, so don't do that

### Upcoming features in some future build
	* More goals, such as setting the amount of crystals/triforces/bosses to be killed to unlock the final bosses
	* More cross-game portals to enable easier cross-game travel
	* More game modes such as keysanity and so on
	* Ability to select the specific games to play instead of always playing all four
